# 📰 NewsHub

NewsHub is a Streamlit-based news application that fetches the latest headlines from around the world using the News API.

The project is containerized using Docker and integrated with Jenkins CI/CD pipeline for automated build and deployment.

---

## 🚀 Features

- 🌎 Fetch latest worldwide news headlines
- 🏷️ Category-based news filtering:
  - General
  - Sports
  - Technology
  - Entertainment
  - Health
  - Science
- 📄 Display news title and description
- 🔗 Direct links to complete articles
- ➕ Show more functionality using Streamlit session state

---

## 🛠️ Tech Stack

- Python
- Streamlit
- News API
- Requests
- python-dotenv
- Docker
- Jenkins (CI/CD)
